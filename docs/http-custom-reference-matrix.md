## Cross-cutting gates for all rows

- Persist every exposed value, validate it at both UI and storage/runtime boundaries, and test defaults, migration, reset, invalid input, process recreation and upgrade behavior.
- Do not surface unsupported protocol or engine controls as active. A disabled control must explain the dependency; otherwise omit it until implementation is ready.
- For proxy/tunnel/protocol features, require controlled endpoint tests plus generated-config/runtime evidence. Emulator UI traversal is necessary for navigation and persistence, not sufficient for network functionality.
- Track Android 9/10+ and ABI differences, lifecycle teardown, permission denial, offline/timeout behavior, logging redaction, and size/licensing review where the feature requires them.
- Use the KVM-backed GitHub Actions emulator for instrumentation. The app must not be built or tested in the local sandbox. Real-device-only routing, hotspot, battery, and OS settings behavior must be explicitly reported as unverified until device-tested.
- The supplied `BACA.TXT` asks for real (non-simulated), optimized features and cites 50 MB APK / 150 MB including data as goals. These are targets, not current measured guarantees.
